# IV Mittaus

Puhelimella toimiva ilmanvaihdon mittauspöytäkirjasovellus (PWA).

## Käyttö

Avaa `index.html` selaimessa tai julkaise tiedostot staattisena verkkosivuna.
Sovelluksen projektit tallentuvat käytettävän laitteen selaimen muistiin.

## GitHub Pages

Repositoryn asetuksissa avaa **Pages**, valitse lähteeksi **Deploy from a branch**
ja julkaistavaksi haaraksi `main` sekä kansioksi `/ (root)`.
